# Grounded diagnostic evidence compiler feasibility

This is a zero-inference engineering study on reused public R2 evidence. Mechanical facts and generic format semantics are frozen in mechanical-contract.json; synthetic mutation effects in mutation-contract.json. No compiler execution can access gold, score files, model answers, classifications, family names, postmortem codes or the scientific scorer. Grouping metadata belongs only to the harness.

Freeze order: commit these contracts and input hashes; implement and run synthetic tests only; commit implementation and test reports; execute all 80 rendered packages representing 20 semantic worlds once for engineering measurement; perform exact replay; preserve all outcomes without post-result code repairs; run preservation and reachable-history audits; publish this branch and stop.

The generic capture semantics are explicitly supplied as an evidence-format assumption. Operational contracts are opaque text. Release ordinal is metadata. Candidate input/output relations are structural possibilities, never causal assertions. The compiler cannot choose the correct decisive field, derive required operational values from prose, determine sufficiency or emit a diagnostic class.

No model calls, server starts, Horus executions, receipts, Memory writes, training, policy changes, architecture promotion or self-improvement proposals are authorized. No fresh two-arm model benchmark is created.
