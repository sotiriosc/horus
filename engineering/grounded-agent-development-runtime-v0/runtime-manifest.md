The startup log reports CUDA architectures `500,610,700,750,800,860,890,900,1200`, CUDA graphs enabled, and CPU AVX2/AVX-VNNI/OpenMP support. Individual upstream CMake flags are not independently published in the archive; they are not inferred here.
- Host: Ubuntu 22.04.5, glibc 2.35, RTX 4090 (24,564 MiB), compute capability 8.9, NVIDIA KMD driver 616.92, CUDA UMD 13.4. The prebuilt binary needs glibc 2.38+ and GLIBCXX 3.4.32; direct launch fails. An **isolated loader**, never installed into the host OS, uses Ubuntu 24.04 `libc6` 2.39 package SHA-256 `ff5557d99b51f761c4b7c92368b9cc45565eda17df9bf9eb4b134d09825008be` and `libstdc++6` 14.2 package SHA-256 `a51f8de7829211db961a31f02158058ad1a95f92ac6d0a5dff6350e2821c54c0`. Their origins are `archive.ubuntu.com/ubuntu/pool/main/g/glibc/` and `/gcc-14/` respectively.
- Isolated asset root: `/tmp/horus-development-runtime-assets`. Model and engine binaries are intentionally not committed. The [`launch-development-server.sh`](launch-development-server.sh) reproduces the pinned launch using the asset root; it changes to the engine directory so the CPU and CUDA backends are both discovered. Default context is 8192; separate 2048 and 16384 launches were tested.
- Launch flags: `--host 127.0.0.1 --port 18081 --n-gpu-layers 999 --parallel 1 --jinja --flash-attn on --metrics --log-verbosity 4` plus the selected `--ctx-size`. The active historical Ollama service stays on port 11434. There was no historical GPU runner during measurements and no concurrent large runner. The development server was stopped after qualification.
- Interface probe: `/v1/chat/completions`, Qwen embedded Jinja template with `enable_thinking=false`, `cache_prompt=false`, fixed temperature 0.2/top-p 0.9/top-k 40/seed 9071. Action calls use a JSON-object schema with exactly one `selected_action` from the supplied allowed enum. This is a new model interface, not a claim of behavioral equivalence to Dolphin Mixtral.
- Benchmark source: [`qualify.py`](qualify.py). Only frozen public-safe synthetic/projection and sanitized retrospective inputs were used; no autonomous world, receipt publication, authorization, or Memory writes occurred.
