# Scientific question

Can a frozen Horus/Qwen incumbent learn an unfamiliar deterministic machine **more efficiently by actively selecting informative experiments** than by receiving the same number of experiments from a fixed passive schedule?

Conceptually:

```text
observe
   ↓
remember what has already been tried
   ↓
consider what is still uncertain
   ↓
choose an experiment
   ↓
execute it
   ↓
authenticated observation
   ↓
compare with prior experiments
   ↓
choose the next experiment differently
```

This study is about:

**active evidence acquisition**

not parameter learning.

# Core design change: controlled experiments

Instead of one continuous 64-action diagnostic trajectory, give the agent a sequence of **controlled probe experiments**.

Every probe begins from the same known machine reset state.

A probe consists of an actuator sequence of length 1–3.

Example:

```json
{
  "probe": ["K7", "Q2", "K7"]
}
```

The simulator resets the machine, executes those actions in order, and returns the observable sensor trace:

```json
{
  "probe": ["K7", "Q2", "K7"],
  "observations": [
    {"V9": 0, "R3": 1, "Z8": 0},
    {"V9": 1, "R3": 1, "Z8": 0},
    {"V9": 0, "R3": 0, "Z8": 1}
  ]
}
```

This creates controlled experiments that can be compared directly.

It allows the agent to test questions like:

- What happens when I use B alone?
- What happens when A precedes B?
- Does reversing A/B change the result?
- Does repeating A matter?
- Does an effect appear only after two steps?
- Does C alter the effect of B?

Resetting before probes removes accidental confounding from an uncontrolled long trajectory while still allowing stateful/delayed effects within each probe.

# Objective information-value evaluator

Create an independent evaluator that is NEVER model-visible.

Given current hypothesis set `H_t`, compute for every available probe:

- partition of H_t by predicted observation trace
- expected posterior hypothesis count
- expected entropy reduction / information gain
- worst-case remaining hypothesis count

For the actually chosen probe, preserve:

- pre-probe |H_t|
- post-probe |H_(t+1)|
- realized hypothesis elimination
- expected information gain
- best available probe information gain
- information-gain regret
- rank of selected probe among the 84 candidates

This does NOT select the active action.

It only tells us afterward whether the experiment was informative.
