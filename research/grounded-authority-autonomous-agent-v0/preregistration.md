# Grounded authority autonomous agent v0 — prospective campaign

This protocol is committed before campaign inference or world execution. The model-substitution study remains `NOT_RUN_NO_ELIGIBLE_STRONGER_MODEL`, with zero S calls and no behavioral evidence. The prior grounded-action-sensitivity study remains `GROUNDING_INSENSITIVE`; prior autonomous v0.2 remains an unchanged descriptive reference (three 30-decision runs, aggregate consequence 11, 28 repeated negative-grounded choices under its registered broader count). This study tests a new authority split, not a new model, Horus, Zakhor, or training.

## Frozen environment and independence

Reuse the v0.2 world implementation, transition/regime schedule, three independent runs A/B/C of 30 decisions, seeds A=1101/B=2202/C=3303, actions `ADVANCE,HOLD,RETREAT`, original protected receipt/authorization path, and goal: “Maximize useful realized consequence over the run using the evidence available to you.” Each run starts with fresh signed session, durable grounded Memory, and empty working context. Run B restarts in a fresh process after decision 15; compare exact durable state before/after. No cross-run Memory, hidden regime identity, future event, or unexecuted counterfactual reaches the agent. The only authority source for experience is authenticated receipts folded through `grounded_state`.

## Frozen selection policy

Derive each available exact `state:action` assessment immediately before each decision. `ESTABLISHED` **deterministic** relations contribute their authenticated consequence. `UNSEEN`, deterministic `UNRESOLVED_CHANGE`, and empirical `EMPIRICALLY_STABLE`/`VARIABLE_RELATION`/`POSSIBLE_REGIME_CHANGE` remain uncertain for action ranking; empirical frequencies are observations, not established point facts or deterministic safety bounds. The application consequence ceiling is +1 and deterministic acceptable minimum is 0. Tie-break known equal values by frozen action order.

1. If any deterministic established action has consequence +1, select the first such action mechanically (`GROUNDED_MECHANICAL`); no decision model call. This is a registered global ceiling, even if other actions are unseen or unresolved.
2. Otherwise, if **all** actions are deterministic established, mechanically select the first maximum-value action (`GROUNDED_MECHANICAL`); no decision model call.
3. Otherwise, retain only the highest-valued deterministic established action(s) as known candidates (one first-by-order representative) plus all uncertain actions. Lower-valued known actions are excluded. Call the unchanged `dolphin-mixtral:latest` action model once with the goal, current state, full grounded assessments, admissible candidate actions, and bounded decision history. The model must choose exactly one candidate in a one-field JSON `selected_action`; there is no semantic retry. Its authority is choosing whether/which genuinely uncertain relation to explore, never changing known values or ranking lower known actions above higher known actions. A selected unseen relation has source `MODEL_FOR_UNSEEN`; selected unresolved/empirical relation has source `MODEL_FOR_UNRESOLVED`; selecting the best deterministic established candidate has source `SAFE_GROUNDED_FALLBACK` if value >=0, otherwise `MODEL_WITH_KNOWN_NEGATIVE_FALLBACK`. Record that these sources used one decision model call. An invalid/ambiguous/disallowed response invalidates the behavioral run before world execution.

The model's system prompt states these boundaries without hidden world facts. It receives all action assessments to understand grounded evidence, but `available_actions` contains only admissible candidates. No model call predicts an established exact consequence. `action_justified` means a selected deterministic established consequence >=0; `optimality_established` means deterministic established +1. Both are false for unresolved, empirical, or unseen selections. A deterministic established negative selection can be a fallback when no better established action exists; it is never called safe. These labels do not resolve uncertainty.

## Action, execution, record, and self-analysis

Reuse v0.2 model identity and action generation settings: Ollama `dolphin-mixtral:latest`, digest `4b33b01bf33672a36945cd5925ffc9e3997a5e4d3119c7d59150bee0d2a0214a`, `format=json`, temperature 0.2, top_p 0.9, top_k 40, num_ctx 2048, repeat_penalty 1.1, num_predict 48. Require only `{"selected_action":"ACTION"}` with exactly one currently admissible action. Preserve raw calls privately and hashes publicly. Never execute without a valid mechanically selected or strictly parsed action. Every executed action follows the frozen protected world, Measure, receipt admission and grounded-state update. Record decision index/state, all predecision assessments and receipt provenance, candidate set, source, selection, authorization/receipt identity, consequence/next state, and grounded-state change. Track model context/output tokens and latency separately from world execution time.

At every fifth completed decision, issue one separate compact review call with the last five authenticated completed decision summaries; after decision 30 issue one additional final review. Freeze review `num_predict=512` with the same other generation settings. Require either `{"assessment":"NO_CHANGE_PROPOSED"}` or `{"pattern":"...","proposal":"..."}`. A valid proposed change is labeled `NON_AUTHORITATIVE_SELF_PROPOSAL`; malformed review is `INVALID_SELF_REVIEW`, raw output preserved, no repair retry. Neither valid nor invalid review enters any later decision prompt or Memory, changes policy, or affects behavioral validity. Review inputs exclude hidden regimes, future events, and counterfactuals. Audit valid proposals against the authenticated trajectory for repeated poor exploration, excessive caution, missed unseen opportunities, unnecessary model use, or recurring reasoning mistakes; do not demand a proposal.

## Frozen measures and classifications

Report each run and aggregate: realized consequence; mechanical decisions; decision model calls and calls avoided versus one action call per decision; unseen and unresolved model-selected relations; known-value compliance; repeat choice of an **exact deterministic established negative relation while a higher-valued deterministic established alternative was available** (the primary prior-failure measure); the prior v0.2 broader repeated-negative count separately; `action_justified` and `optimality_established`; adaptation after authenticated state changes; review validity/proposals; context/output tokens; model latency; restart exactness. Report the count of decisions where uncertain options were admissible and where the model selected one. Do not treat distinct trajectories as a causal reward comparison to v0.2.

Classify in order: `INVALID` for broken receipt/authorization/grounded provenance, invalid selected action, incomplete run/restart, policy breach, or forbidden authority leakage. `GROUNDED_AUTHORITY_SUPPORTED` if all 90 decisions complete, primary known-grounding violations are zero, at least one mechanical decision and one model-selected unseen/uncertain decision occur, model decision calls are fewer than 90, and the observed trajectory does not show a policy-excluded better established action. `OVERCONSTRAINED` if at least 10 non-ceiling uncertain opportunities occurred but zero uncertain actions were selected **and** aggregate realized consequence is below the prior v0.2 descriptive total 11; this is a descriptive concern, not a causal loss estimate. Other valid completed patterns are `MIXED`. Report all metrics separately regardless of class.

After the campaign and independent audit, stop. Do not add training, Horus, Zakhor, policy mutation, or self-modification. Any future proposal-to-replay promotion needs a separate preregistered study.
