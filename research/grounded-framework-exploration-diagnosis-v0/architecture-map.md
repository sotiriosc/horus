# Current grounded-agent architecture (Phase 1)

This is a read-only map of the executable grounded-authority campaign at `0d3efe0`, using its sanitized [result](../grounded-authority-autonomous-agent-v0/result.md) and [public trajectory](../grounded-authority-autonomous-agent-v0/public-result.json). It describes the current research substrate, not a new controller. Horus and Zakhor are parked historical systems; `horus.live.SessionStore` is reused infrastructure, not Horus decision authority. No model or world call was made for this map.

| Component / source | Input | Output | State owned | Authority and allowed change | Forbidden change / boundary cost |
| --- | --- | --- | --- | --- | --- |
| Protected execution, [`ExternalExecutionBoundary`](../../experiments/realized_event_grounding_v0/receipt.py) and [`ScheduledWorld`](../../experiments/grounded_autonomous_agent_v0_2/worker.py) | Frozen action, pending transaction, current world | Realized next state and consequence; original receipt after execution | World state, pending original receipt, execution count | Execute once and mint/retire current receipt; candidate receives only read port | Candidate cannot mint/rewrite receipt. Execution is bounded; no counterfactual outcome is available. |
| Receipt/package gate, [`RealizedEventFramework`](../../experiments/realized_event_grounding_v0/framework.py) | Current original receipt, pending proposal, package bindings | Bound A/B adapter receipts and committed/rejected result | Bounded package ring and protected pending state | Require identical original receipt object and exact transaction/content binding | Equal fabricated fields or source agreement cannot confer origin. Object identity is a prototype capability, not hostile same-process security. |
| Measure and authorization, [`CrossSourceFramework`](../../experiments/base_framework_v1/framework.py) via protected wrapper | Pending prediction and receipt-bound adapters | Measurement match, authorized/rejected publication | Protected prediction, pair decisions, bounded core Memory | Validate and commit only authorized realized event | Prediction cannot replace observed consequence; failed validation cannot enter authoritative Memory. More checks and storage cost. |
| Signed event store and durable [`ModernMemory`](../../experiments/modern_memory_vs_horus_v0/storage.py) | Authorized event envelope, receipt identity/hash and core Memory record | Exact-relation chronological rows and reconciliation | Signed streams/checkpoint; SQLite event rows and provenance | Admit only current authenticated publication; reconcile store and rows | Cannot accept stale/unauthorized/mismatched evidence. Chronological provenance grows with receipts. |
| Deterministic fold, [`grounded_state/deterministic.py`](../../grounded_state/deterministic.py) | Authorized exact `(state, action)` rows | `UNSEEN`, `ESTABLISHED`, or `UNRESOLVED_CHANGE`; support identities | Derived state, rebuilt from Memory | First receipt establishes; contradiction suspends certainty; next matching receipt can resolve | Cannot silently promote a third value or let prediction edit the fold. Revisiting a relation is required to gain evidence. |
| Empirical fold, [`grounded_state/empirical.py`](../../grounded_state/empirical.py) | Authorized rows for explicitly empirical relation | `UNSEEN`, `EMPIRICALLY_STABLE`, `VARIABLE_RELATION`, `POSSIBLE_REGIME_CHANGE`; counts/windows/provenance | Derived segment/history, rebuilt from Memory | Represent variation separately from possible sustained change | Cannot assert deterministic safety or discover relation type automatically. Full provenance increases footprint. |
| Assessment interface, [`grounded_state/core.py`](../../grounded_state/core.py) | Explicit relation type and derived state; optional generalization | Status/kind/evidence/provenance | None beyond derived view | Expose grounded facts; generalization only attached to `UNSEEN`, with `model_has_authority=False` over facts | Cannot turn model guess into grounded relation; status `GROUNDED` for empirical stable/variable still does not make a deterministic point value. |
| Candidate routing, [`protocol.py`](../../experiments/grounded_authority_autonomous_agent_v0/protocol.py) | All three assessments and fixed action order | Mechanical action or admissible candidate set | No durable state | Select established deterministic `+1` ceiling, or best when all established; otherwise retain best established representative and every uncertain candidate | Cannot offer inferior established alternatives in mixed route. No information-value or stagnation calculation; uncertain candidates remain open. |
| Action model and strict parser, [`worker.py`](../../experiments/grounded_authority_autonomous_agent_v0/worker.py) | Goal, state, candidates, assessments, at most three recent decisions | Exactly one admissible `selected_action`, or invalid stop | Frozen model call ledger; no grounded state | Choose only inside mixed-route candidate set; valid selection then freezes before execution | Cannot execute invalid action, alter candidates, Memory, receipt or rules. Calls consume inference time; repeated calls may choose the same fallback. |
| Separate self-review and restart | Five completed decisions/receipts for review; signed streams and checkpoint for recovery | Review validity/proposal as non-authoritative data; reconstructed durable snapshot | Review ledger; persisted session and Memory | Review may describe only; restart reconciles/rebuilds grounded state | Reviews never feed later decision prompts or modify policy. Review calls can be costly and invalid; restart has storage/replay cost. |

The active mixed route calls the model even when it eventually chooses a known nonnegative action. `SAFE_GROUNDED_FALLBACK` is a **source label for that model choice**, not the earlier hybrid H_SAFE mechanical policy. The action route and one-field parser are the last decision authority before the protected execution port. See [authority-map](authority-map.md) and [uncertainty-map](uncertainty-map.md) for the two cross-cutting traces.
