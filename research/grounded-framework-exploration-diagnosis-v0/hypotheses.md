# Bounded explanatory hypotheses (Phase 2)

These are falsifiable interpretations of the completed record, **not** approved features or policy changes. A later Phase 3 would separately preregister one bounded proposal, preserve the incumbent as control, and predict effects before any evaluation. No rule or threshold is selected here.

## H1 — repeated fallback leaves exploration optional

**Mechanism.** In a mixed route the frozen selector offers all uncertain actions and the best known deterministic action, but has no information-value or no-progress state. A model can select the known action repeatedly without acquiring evidence about alternatives.

**Evidence.** In [Run C](run-c-trace.md), D05–D30 offered both unseen alternatives alongside established-zero HOLD; the model chose HOLD 26 times, and only its support count grew. The [source route](../../experiments/grounded_authority_autonomous_agent_v0/protocol.py) has no stagnation input.

**Prediction.** If this mechanism materially explains the loop, changing only the mixed-route handling of repeated known-zero selection in a separately registered matched study should change the *distribution of executed relation identities and newly acquired exact-relation evidence* under C-like decision contexts. It need not improve reward.

**Falsifier.** A matched change to that one mechanism that leaves relation sampling and grounded discovery unchanged would weaken H1. A different hidden outcome cannot be presumed in advance.

`POSSIBLE_PHASE_3_DIRECTION`: investigate whether mixed-route choice should account for information acquisition. No action-selection rule is designed here.

## H2 — model-only evidence presentation is unreliable for known-fact comparisons

**Mechanism.** A one-field action model may repeat an action prior despite materially changed grounded assessments; deterministic routing supplies the needed known-fact precedence outside the model.

**Evidence.** The [sensitivity study](../grounded-action-sensitivity-v0/report.md) found 0/9 paired swaps changing action in each tested prompt condition; [grounded authority](../grounded-authority-autonomous-agent-v0/result.md) mechanically took 28 ceiling actions and had zero narrow known-negative-with-better-established violations.

**Prediction.** If the model-only presentation mechanism is responsible for that narrow class, removing mechanical precedence in *separately matched fixed contexts* should restore evidence-invariant or known-inferior choices more often than retaining it.

**Falsifier.** If matched model-only selections reliably track the grounded value and avoid the narrow known-inferior choice under the same context, the mechanism is weakened. Current evidence does not license a claim of universal model incapacity.

`POSSIBLE_PHASE_3_DIRECTION`: preserve and separately stress-test the incumbent mechanical authority boundary; this is not authorization to relax it.

## H3 — retrospective output failures are interface/transport constraints, not yet assessed self-analysis quality

**Mechanism.** Review formats and transport completion prevent obtaining scorable retrospective records, so the study cannot observe whether the model can use receipts to diagnose its own behavior.

**Evidence.** [V0.2](../grounded-autonomous-agent-v0.2/result.md) had 21 invalid reviews; [current authority](../grounded-authority-autonomous-agent-v0/result.md) had only three valid `NO_CHANGE_PROPOSED` reviews; [self-diagnosis](../grounded-self-diagnosis-v0/result.md) received no text across three logical calls/six timeouts.

**Prediction.** If interface completion is the limiting factor, a separately preregistered, otherwise matched retrospective interface that returns valid bounded records would make semantic auditing possible. It does **not** predict that the resulting diagnoses will be correct.

**Falsifier.** If valid, completed review records are obtained yet consistently misread receipt evidence, interface completion alone cannot explain poor self-analysis; a reasoning limitation would then be observable.

`POSSIBLE_PHASE_3_DIRECTION`: study retrospective interface reliability separately from behavioral authority. This milestone makes no interface modification.

H1 concerns exploration in a mixed route; H2 concerns adherence to *known* exact facts; H3 concerns whether retrospective text is available to evaluate at all. Their predicted observations differ, and none grants self-review authority or assumes unseen outcomes.
