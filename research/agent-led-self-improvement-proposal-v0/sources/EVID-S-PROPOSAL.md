# Bounded stagnation escape — Phase 3 proposal only

**Status: proposed, frozen for a future matched test; unimplemented and untested.** This branch starts from the completed [Phase-1/2 diagnosis](../grounded-framework-exploration-diagnosis-v0/phase-3-readiness.md) at `9bc4ab83b828e465241ea168ef84567226ffa857`. That branch and the completed [grounded-authority campaign](../grounded-authority-autonomous-agent-v0/result.md) remain unchanged. No model calls, world actions, training, or live campaign belong to this milestone.

The single selected hypothesis is [H1](../grounded-framework-exploration-diagnosis-v0/hypotheses.md): a mixed route leaves exploration optional after repeated neutral fallback. The authenticated [Run C trace](../grounded-framework-exploration-diagnosis-v0/run-c-trace.md) shows state 0, deterministic established `HOLD=0`, two unseen alternatives, and 26 consecutive model-selected HOLD fallbacks. Only HOLD support increased. This observation does **not** reveal the consequences of either unseen action.

Proposed candidate `S = STAGNATION_ESCAPE`: after **three consecutive qualifying same-state neutral-fallback executions**, the *next* decision mechanically selects exactly one still-unseen action to acquire an original authenticated receipt for that exact relation. Then the incumbent route resumes. The purpose is `ACQUIRE_MISSING_RELATION_EVIDENCE`, not predicted reward gain. [Candidate rule](candidate-rule.md) fixes eligibility, action order, reset, and recovery semantics.

`I = INCUMBENT` is the exact frozen [grounded-authority protocol](../../experiments/grounded_authority_autonomous_agent_v0/protocol.py) and [worker](../../experiments/grounded_authority_autonomous_agent_v0/worker.py). S differs only at this one decision boundary. Receipt origin, Measure, authorization, signed event publication, ModernMemory admission, both grounded folds, `UNRESOLVED` meaning, established `+1` mechanical authority, normal model authority outside the trigger, and restart/replay integrity remain invariant. No source or incumbent policy file changes in this branch.

The threshold **3** is frozen prospectively. One neutral fallback may be ordinary caution; two may still be transient repetition; three show repeated same-state choice without sampling an available unseen relation. This threshold is far below Run C's 26-step observed loop, but it is not fitted to guarantee reward or even beneficial exploration. It must not be tuned during Phase 4.

```text
EXPLORE:  Run C repeatedly chose known zero while unseen alternatives remained.
DIAGNOSE: The incumbent permits this because mixed-route exploration is optional.
PROPOSE:  After three qualifying executions, sample one canonical unseen relation.
PREDICT:  New exact-relation evidence appears and the zero-fallback streak breaks.
EVALUATE: Future matched incumbent-versus-candidate study, not this milestone.
```

This proposal was generated by the external research process, **not by the action model or its self-review**. It does not promote itself.
