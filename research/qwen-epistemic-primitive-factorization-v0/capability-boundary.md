# Capability boundary — Qwen Epistemic Primitive Factorization v0

The registered interpretation is **A: PRIMITIVES_ESTABLISHED_REDUCTION_NOT_ESTABLISHED**. Every one of the seven primitive gates passes with 8/8 exact endpoints and 4/4 directional matched-pair passes. Five-class reduction on the same aligned state objects scores 41/56 and fails its independently frozen gate. All 112 outputs satisfy their schemas.

This establishes the requested bounded contrast: the individually queried judgments are reliable on their frozen tests, while selecting the five-class diagnosis from those aligned factual states is not. It identifies a reduction/ontology-composition bottleneck at the level of these measured tasks. It does not establish an internal causal mechanism, complete simultaneous mastery of every primitive on every state, or a repaired architecture.

2. **Currentness:** established, 8/8 and 4/4. The answer tracks explicit deployment even when the designated observation belongs to an older or newer non-serving build. This is temporal applicability, not evidence of a defect.

3. **Known versus unknown:** established, 8/8 and 4/4. The model tracks captured versus unresolved inputs in the designated tests, without treating measured output as proof of contract compliance. These target cases have internally consistent assertions.

4. **Contradiction detection:** established, 8/8 and 4/4. The model correctly separates unequal marks on different immutable subjects from unequal marks on the same complete build/station/cycle tuple, and handles agreeing duplicates. Every contradiction-target flip also changes one identity/equality component; the result is not a causally orthogonal test of those two constructs.

5. **Alternative-completion existence:** established, 8/8 and 4/4. The model tracks whether an input distinct from the explicit reference remains allowed. Two pairs preserve the compliance conclusion when an alternative is added; two change decision relevance. Every target pair also changes knownness because a singleton remaining domain expands to two possibilities.

6. **Observation versus requirement:** established, 8/8 and 4/4. The model compares the designated trial's observed output with the supplied requirement at its explicit reference completion. This includes non-serving observations and a package with an independent mark disagreement. It is not a final diagnosis or a claim that an unresolved reference completion is actual.

7. **Evidence sufficiency:** established for the narrowly defined operational proposition, 8/8 and 4/4. The input remains uncaptured with three admissible completions on both sides. The model correctly distinguishes all completions giving the same violation truth value from completions giving different truth values. All six non-target primitive golds stay fixed in these four pairs. The target states remain internally consistent. DETERMINATE does not itself report whether the uniquely determined violation proposition is true or false, and it does not select a diagnostic class.

8. **Five-class epistemic reduction:** not established, 41/56 (73.2%) against a minimum of 48/56. Current defect, insufficient evidence and historical defect miss their floors. Reduction passes 11/19 class-changing pairs and preserves the correct class at both endpoints in 5/9 class-stable controls.

9. **Primitive correct but reduction wrong:** yes, fifteen matched states. By target family the counts are identity 0, currentness 2, knownness 3, contradiction 1, alternatives 3, comparison 1 and sufficiency 5. The remaining 41 states have both measured answers correct. There are no primitive-wrong endpoint outcomes in this run. At pair level, sixteen pairs pass both tasks and twelve pass the primitive task but fail exact reduction-pair scoring.

10. **Which limitation is supported:** the exact registered Pattern A, a bounded reduction/ontology-composition limitation. No primitive gate failed in this study, so the data do not identify a missing target primitive under these tests. This conclusion applies to this new benchmark and does not reinterpret the preceding completed study. It does not imply that every latent intermediate judgment inside a reduction call was correct.

## What the study does and does not identify

Each state has one designated primitive query plus a separate reduction query. The offline seven-primitive truth vector is author gold for coupling checks, not seven measured model responses. Consequently the study does not establish that the model could answer all seven primitives correctly on every state, nor that it internally computed them correctly before a wrong reduction answer.

Primitive questions explicitly direct attention to a narrow relation and define the requested judgment; the reduction instruction supplies the unchanged five-class ontology. Task instruction, response format and responsibility scope differ intentionally, while state bytes remain identical. The observed contrast does not distinguish label mapping, attention allocation, aggregation, reasoning-budget sensitivity or another internal explanation. No alternative prompt or runtime condition was tested.

There are only four pairs per primitive, one sample per endpoint/arm and one prospective seed. Fifteen pairs have necessary non-target coupling; thirteen do not. Cases share a finite symbolic-table grammar and are internally authored. The results support the preregistered bounded gates, not population-wide reliability, independent external generalization, raw evidence binding, operational arithmetic or end-to-end diagnosis. No significance or causal attribution claim is made from the correlated 112 calls.

All calls ended with finish_reason=stop; completion tokens range from 11 to 534 and the largest prompt is 963 tokens, below the frozen 2048 completion and 16384 context limits. Runtime reasoning remained enabled at budget512. In five primitive envelopes the optional separate reasoning_content field was absent; 107 envelopes supplied a reasoning string. The five short finals contain no reasoning-channel markers. The frozen transport allowed this, raw bytes remain unchanged, and scoring uses only final output. This provenance fact does not establish why the model gave any answer.

## Model, deterministic software and combined-system capability

**Model capability:** seven separately tested primitive gates pass; five-class reduction fails on the matched aligned states. No model weights, Memory-conditioned behavior or settings were changed, and no learning occurred.

**Deterministic software capability:** direct case serialization, independent finite-domain gold verification, pair-coupling checks, strict scoring, hashing and replay succeeded on this specification. Those functions validate the experiment. Their answers were not provided to Qwen as primitive or reduction conclusions. The prior evidence compiler was never used.

**Combined-system capability: NOT TESTED.** No primitive output was chained to another call, no helper composed a model judgment vector, and no software substituted an answer for a missing model response. These results do not demonstrate a hybrid repair, Horus self-improvement or RSI. No intervention, comparator or next study is designed or executed.
