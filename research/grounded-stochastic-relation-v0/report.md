The empirically stable label means **only that all observations in the current segment agree**; it makes no claim that other outcomes have zero probability. This observation-relative meaning survives the study, as do exact-relation scoping, authenticated receipt admission, provenance, restart reconstruction, and model generalization only for unseen relations. The deterministic `ESTABLISHED / UNRESOLVED_CHANGE` rule remains appropriate for relations known to be deterministic. Evidence supports a typed architecture in principle; automatic type discovery was neither tested nor implemented.

The two F histories share the same first ten observed exact-relation receipts. At that point E is `VARIABLE_RELATION` in both, and the correct audit result is `EVIDENCE_INSUFFICIENT_TO_DISTINGUISH`. No receipt-only system can know which future will occur from that prefix. Subsequent continued variability produces no E warning; a sustained run in the other future produces one. This bounded result does not establish calibrated statistical detection for arbitrary stochastic processes. A chance run of four uncommon outcomes could cause a false alarm in a longer stationary process, and subtle shifts that do not create a four-identical-outcome run may be missed. The schedule is a prospectively fixed set of realized traces, not a Monte Carlo estimate of these risks.

The existing deterministic H_SAFE threshold cannot be treated as a guarantee for variable outcomes. A relation whose observed consequences are usually nonnegative may still produce a negative consequence. Calling that action “safe” would require application-specific risk semantics or a proven lower bound, neither supplied by empirical frequency alone. H_SAFE and the hybrid controller remain unchanged.

Answer to the architecture questions: **yes, for the registered histories, authenticated empirical state can represent “reality varies” separately from “possible change,” with an explicit indistinguishable-prefix boundary.** The deterministic architecture's receipt trust boundary, exact relation history, provenance, restartability, and deterministic relation rule survive; its single-value established state is insufficient as the sole representation for variable relations. Stop here; no controller or planner modification follows from this study.
