## Frozen semantic and latency gates

A valid Stage A passes the **joint semantic gate** only if: (1) at least two distinct selected action names occur; (2) the grounded +1 value swap makes A1 select ADVANCE and A2 select HOLD in **all three matched display orders**; (3) the B established/unseen swap changes the selected action in at least two of three matched display orders; (4) no universal HOLD fixation; and (5) A1 and A2 choices remain stable across all their display orders, so their value response is not explained solely by display position. C1/C2, D and E are descriptive controls: report established-negative and unresolved selections, order stability, unseen selection and action-name distribution without unobserved payoff labels. The B test asks for status sensitivity, not presumed payoff optimality; choosing the neutral or unseen side consistently can both count as semantic responsiveness. The frozen latency gate is **median warm Stage A action wall time <15 seconds** across all 19 calls on an already loaded server. Record prompt tokens, reasoning token count (exact if supplied, otherwise pinned-local-tokenizer proxy), final-output token proxy and wall time for every call. Do not relax any criterion after seeing outputs.

If the interface passes but the semantic gate fails, classify `THINKING_DOES_NOT_FIX_POLICY`. If semantic gate passes but latency fails, `THINKING_TOO_SLOW`. If both pass, `QWEN_BOUNDED_THINKING_SEMANTIC_GATE_PASSED`. Any read-only/integrity violation is `INVALID` and takes precedence over other classifications. A clean pass suggests a **separately authorized** short autonomous study only. There is no Stage B in this branch.
