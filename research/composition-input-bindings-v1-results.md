## 4. Unchanged authority architecture

Only the new experiment directory implements bindings and deterministic tests.
Action admission, Prediction type/latch, external receipt root, Measure, Memory,

## 5. Generalized Explorer binding

The existing coordinator supplies authorized state and audited Memory to `choose`.
The deterministic projection contains `state` and three `actions`; each entry has
an opaque `action` token and `verified_outcomes`, a chronological consequence list
or `UNTRIED`. Records sort by epoch/transaction, filtered by current state/action.
Only the two registered families and their complete bijective mappings are allowed.
Transport receives compact sorted JSON and a seed, never framework objects.

## 6. Empty-Memory UNTRIED semantics

UNTRIED denotes no authenticated observation. It creates no event, zero consequence,
receipt, preference or ban. All three actions remain offered, including actions with
negative evidence. The new Explorer shape was frozen before implementation because
the historical complete-history shape cannot express the required initial context.

## 7. Explorer empty-domain tests

48/48 contexts passed: four states × two families × six mappings. Every context
contains exactly the three opaque actions, each UNTRIED; repeated serialization is
byte-stable and contains no canonical action names. Memory remains empty.

## 8. Mixed-history tests

48/48 mixed contexts passed. Ordinary receipt publication of HOLD,HOLD,ADVANCE,
RETREAT returns to each fixture's initial state with HOLD observed twice, ADVANCE
once, and RETREAT untried at that state. Projections preserve chronology even when
the input iterable is reversed, retain all actions and leave records unchanged.
These stationary fixtures include positive, zero and negative outcomes where
permitted. A further 48 complete-history comparisons preserve the old opaque
Explorer evidence content/order; their JSON shapes intentionally differ.

## 9. Generalized Map binding

The coordinator calls `predict` after ordinary action admission. The binding uses
its current Map state, that admitted underlying action, and the same staged Memory
object. It projects only exact-pair authorized records, then invokes the unchanged
finite prediction parser. Deepcopy preserves the Map-to-staged-Memory reference.
No context cache or experiment-side history supplies experience.

## 10. Map empty-history semantics

An untried pair produces `VERIFIED_CHRONOLOGICAL_HISTORY: []`. It remains valid input
for a bounded proposal. No consequence default, inferred prior, copied other-pair

## 34. Limitations

This establishes deterministic finite-domain input binding and tested authority
preservation. Synthetic values are scheduled fixtures, not model predictions.
The eight-step episode is bounded, stationary and unoptimized. This is not a
representation-neutrality experiment, proof against arbitrary faults/hostile Python,
or evidence of model composition behavior, learning or adaptation. Explorer's new
projection shape has no live-model behavioral validation. A future live integration
must still bind each genuine Recovery request's context without privileged future
fixture knowledge; this campaign reuses the historical registered-context proposer.
Trusted coordinator, external event emitter and authorizers remain trust boundaries.
