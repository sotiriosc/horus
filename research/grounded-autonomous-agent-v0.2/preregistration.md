## Frozen interfaces and limits

The **authoritative action call** receives the persistent goal, current world state, allowed actions, current grounded assessments, and up to three permitted previous decision summaries from the same process stage. It is asked to output only `{"selected_action":"ACTION"}`. Request `format="json"`; inherited sampling parameters are temperature `0.2`, top_p `0.9`, top_k `40`, num_ctx `2048`, repeat_penalty `1.1`; action `num_predict=48`. The parser accepts exactly one JSON object containing exactly one `selected_action` field whose string is in the currently allowed set. Duplicate fields, extra fields, malformed JSON, prose, absent/disallowed actions, and ambiguity are invalid. No action is salvaged from malformed output. The existing two semantic attempts remain; after two invalid outputs, stop before world execution. Transport repair behavior is inherited unchanged. Once parsed, the action is signed as `ACTION_FROZEN` before any commentary call. No later text can replace it.

A **pre-consequence decision-commentary call** is made after each frozen action and before execution. It receives the frozen action and the same pre-decision context, never the new consequence. Its `format="json"` and `num_predict=192`; sampling parameters and model remain the same. It requests `reason`, `evidence_source`, `reliance`, `claimed_status`, and `claimed_consequence`. A missing, malformed, or truncated output is `INVALID_DECISION_COMMENTARY`; its raw response is retained privately and no field is invented. There is one commentary call and no semantic retry. Commentary cannot change or block the action, alter grounded Memory, or become authoritative evidence. If valid, it is preserved as the agent's non-authoritative decision-time interpretation; disagreement checks use only explicit well-formed claims. Commentary transport failure is recorded as invalid commentary and does not veto execution.

**Execution** uses only the frozen action through the existing protected controller and original authenticated receipt. The receipt is measured, authorized, stored durably, and folded into grounded Memory. The non-authoritative commentary does not enter the receipt or grounded-state fold.

**Self-review** occurs after decisions 5, 10, 15, 20, 25, and 30, plus one distinct final review after decision 30 (seven per complete run). Each receives a bounded structured record of only the latest five completed decisions, including pre-decision assessments, frozen action, valid commentary if any, authenticated realized consequence and next state, grounded change, disagreement, and receipt provenance. The final review also receives `final_review=true`. It receives no hidden regime, unexecuted counterfactuals, future events, simulator tables, or evaluator labels. The compact output is exactly an object with `assessment` (`NO_CHANGE_PROPOSED` or `CHANGE_PROPOSED`), nonempty `pattern`, and nonempty `proposal`; for no change, the proposal is literally `NO_CHANGE_PROPOSED`. Decision IDs and provenance are attached mechanically by the harness, not emitted by the model. `format="json"`, `num_predict=512`, and inherited sampling parameters are frozen. One review call, no semantic retry. Invalid output is `INVALID_SELF_REVIEW`; no proposal is inferred. Every review is non-authoritative, and before/after checks require no event, Memory, world-state, or grounded-assessment change. Neither valid nor invalid review output enters any later action prompt.

Action seeds remain `RUNS[run]+index`; commentary seeds are `RUNS[run]+index+20000`; scheduled review seeds are `RUNS[run]+index+10000`; final review uses `index+100` as its call index and corresponding seed. This interface change affects output collection only and is frozen before inference. Run B starts its second stage in a fresh process after an exact durable snapshot comparison. Its recent decision working context resets at decision 16; authenticated Memory survives.

## Independent validity and analysis

`behavioral_run_status=VALID` requires 30 executed allowed actions, 30 original authenticated receipts, replayable grounded Memory, no invalid action executed, and compliance with frozen stop/repair rules. A failed commentary or review does not change behavioral validity. `self_review_status=VALID` requires all seven scheduled reviews valid; otherwise it is `PARTIAL_OR_INVALID`. If every review fails across the campaign, report `SELF_ANALYSIS_NOT_ESTABLISHED`. A run stopped for two invalid action parses is behaviorally invalid, and its partial trajectory cannot be promoted as full-run evidence.

Report action calls, commentary calls, review calls, transport attempts, invalid/truncated outputs, realized consequence trajectory, repeated actions after grounded negative outcomes, established-evidence reliance, unseen exploration, unresolved decisions, adaptation after relation changes, grounded/agent disagreement, and restart coherence. Audit each valid proposal independently against preserved authenticated trajectory as supported, partially supported, hindsight overfit, contradicted, untestable, or no change. Distinguish ignored evidence from insufficient evidence, unsupported explanations, and reusable proposals. No self-modification, rule mutation, prompt rewriting, training, or model-weight update is authorized.

Private HMAC keys, raw calls, signed streams, and databases remain local. A publishable result may contain sanitized trajectories, replay verdicts, private-artifact SHA-256 digests, and explicit archival provenance only. Audit all reachable publication history before pushing.
