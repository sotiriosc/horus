## Current trust roots and limitations

1. **External simulator/emitter:** defines the executed event. A world that lies or differs from physical reality cannot be corrected by agreeing downstream copies.
2. **Original receipt issuer:** must mint only after execution, report it honestly and retain the correct current object. Equal-value copies do not establish origin.
3. **Host process/runtime:** owns Python objects and capabilities. This is not protection against malicious same-process reflection, arbitrary memory mutation, code replacement, races outside the documented coordinator, or compromised hardware/OS.
4. **Enrollment/registry:** the trusted driver binds the correct receipt port and lifetime source identity. The old v2 process registry is not reality authority in this root. No cryptographic enrollment or physical source independence is demonstrated.
5. **Coordinator and parsers/projections:** must enforce finite admission, immutable pre-outcome prediction, status/scope ownership, original binding, atomic publication and honest projection. Models receive serialized values, not capabilities.
6. **Filesystem/recorder:** hashes and retained traces establish consistency conditional on honest recording. They do not recreate lost evidence or prove truth against a consistently fabricated archive.
7. **Local inference runtime identity:** retained model/runtime identity, response honesty and hidden server state remain assumptions for historical behavioral claims. This rebaseline did not contact the server. No application context reuse was found by the prior audit; that is not proof of absent server hidden state.

The mutation/control suite is bounded, not an exhaustive proof of all adversaries. The minimal root is a software simulation architecture, not a completed RTL implementation of every component. Same-root A/B compatibility fields are deliberately not independent observations. Read-only prior-receipt, declared-law and detached-world scoring are labeled separately from post-prediction authenticated receipts. The missing original v2 run cannot be reconstructed by this report.
