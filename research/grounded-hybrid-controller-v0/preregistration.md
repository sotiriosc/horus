# Grounded hybrid controller v0 — frozen before live inference

Parent: `research/grounded-uncertainty-state-v0` at `b4d8c0761f0b414bcad25da995c060a169e1fbac`, classification `EXPLICIT_UNCERTAINTY_SUPPORTED`. Its evidence is immutable. Protected receipts, Measure, authorization, and the existing ModernMemory remain the sole source of grounded state. No Horus router, Zakhor, planner, Explorer, training, or scalar confidence model is introduced.

Nine independent scenarios in `protocol.py` seed matched exact-relation histories in three independent protected sessions. Seed actions are explicitly observation-controlled and use a neutral bound prediction solely to enter the existing protected execution path; their realized receipts, not that prediction, create Memory. At each decision, the HYBRID/MODEL/FORCED_GROUNDED arms start from matched authenticated seed observations and independently choose and execute or abstain. Post-decision histories can diverge, so realized consequences compare action choices in the same initial world, not matched post-action trajectories. E includes a second within-arm decision after a protected return to state 1, demonstrating the selected relation's change from model generalization to grounded authority; those second histories are descriptive and not claimed matched across arms. H splits seed and decision into fresh processes.

HYBRID assesses each candidate exact relation. `ESTABLISHED` becomes `GROUNDED` with that value and receipt provenance, zero model calls. `UNSEEN` becomes `MODEL_GENERALIZATION` using the exact frozen two-call joint Map + G2 model, labeled as prediction. `UNRESOLVED_CHANGE` becomes `UNRESOLVED` with established/candidate values, count, and receipt provenance; no model tie-break. Every assessment contains action, status, value if available, provenance, and source. MODEL uses the same frozen pair for every candidate. FORCED_GROUNDED uses the latest authenticated receipt for each exact relation, or neutral consequence 0 and identity next-state if unseen, always returning a point.

The existing protected world's registered consequence domain is [-1,+1] in all frozen actions and regimes. The decision objective is one-step realized consequence. HYBRID first chooses a `GROUNDED` action at +1, since no action can exceed the registered maximum; an unresolved competitor could tie but cannot outperform it. If any action is unresolved and no grounded +1 exists, HYBRID abstains because the unresolved action could alter the winner. Otherwise choose the highest consequence point among grounded and model-generalized actions, preferring grounded on ties and then the registered action order `ADVANCE,HOLD,RETREAT`. MODEL and FORCED_GROUNDED choose their highest point with the same action-order tie rule. This comparator does not claim a model prediction is grounded, and does not interpret an unresolved old/candidate value as current truth. Invalid preparation stops the scenario rather than silently substituting a point.

Scenario A has all three actions established. B compares established HOLD with unseen ADVANCE. C has grounded HOLD +1 and unresolved ADVANCE after B→A; ceiling selection can proceed without claiming ADVANCE's current value. D has unresolved HOLD whose previously established +1 could be best, versus grounded ADVANCE −1, so HYBRID abstains. E starts with three unseen actions; its first selected relation acquires an authenticated receipt and is reassessed at a second decision. F confirms a contradictory HOLD candidate in B; G confirms restoration in A; H restarts while HOLD is unresolved and RETREAT established; I rejects the one-event HOLD anomaly in A. F and I share H's four-observation exact value prefix but have opposite next HOLD receipts, so H's contradiction is an explicit information boundary. A failed, non-current Memory admission is injected after H's restart; no receipt, Memory row, or derived state may change. The external regime is hidden from every decision policy and model prompt.

A serialized receipt-derived state is measured per assessed relation for transient memory cost; operational Memory stores no extra materialized U state. Decision training logs retain assessment provenance for audit, and their disk use is reported separately. Primary reporting keeps separate: realized consequence, decisions versus abstentions, incorrect confident actions (selected action's registered point differs from its realized consequence), retrospectively unnecessary abstentions (a uniquely best realized action existed, reported separately from epistemic justifiability), grounded/model/unresolved source usage, calls avoided or required, adaptation after confirmation, anomaly rejection, restoration, restart and perturbation integrity. Epistemic correctness requires every HYBRID `GROUNDED` assessment to be backed by ESTABLISHED receipt state; every `MODEL_GENERALIZATION` assessment by UNSEEN state; every `UNRESOLVED` assessment by unresolved state; no model call on established or unresolved exact relations. A changed hidden regime may make a previously established value differ on the next event; this is a prospective prediction error, not evidence fabrication. At matched contradiction prefixes, unresolved status is required even when a forced point baseline happens to choose well.

The frozen classification is `GROUNDED_HYBRID_SUPPORTED` if receipt/restart/perturbation/replay integrity passes, all epistemic statuses are correct, the autonomous policy executes useful actions in A/B/C/E/F/G/I, abstains explicitly at D/H, and the selected E relation moves from model generalization to grounded authority. `MODEL_DEFAULT_SUPERIOR` takes precedence if, among matched first decisions where both execute, MODEL has higher realized consequence in at least three scenarios, HYBRID in none, and MODEL's summed advantage is at least three consequence units. `FORCED_POINT_SUFFICIENT` applies if HYBRID and FORCED_GROUNDED select the same first action or abstention in all nine scenarios. `MIXED` applies when integrity passes but none of those or the support criteria hold; integrity failure is `INVALID`. These labels are architectural observations in a small deterministic simulation, not a general performance ranking.
