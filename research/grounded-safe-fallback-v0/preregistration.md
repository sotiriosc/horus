# Grounded safe fallback v0 — frozen before live inference

Parent: `research/grounded-hybrid-controller-v0` at `dbe9894abfcbfea107d6cc30cf4a1ccf3a3108b0`, classification `GROUNDED_HYBRID_SUPPORTED`. Its evidence remains immutable. The protected receipt → Measure → authorization → ModernMemory → receipt-only grounded-state path and frozen M/L prediction definitions remain unchanged. No Horus router, Zakhor, planner, Explorer, training, or scalar confidence model is added.

The registered consequence domain is `{-1,0,+1}` with the existing ordering `+1 > 0 > -1`. `horus/core.py` explicitly describes 0 as *neutral* in the authenticated-history consequence adapter; previous registered studies also use neutral 0. In this finite simulation only, the acceptable threshold is therefore a grounded consequence `>=0`. It is an application decision criterion, not evidence that a relation is optimal or that future external regimes cannot change. If this neutral meaning had not already been registered, this study would stop instead of inventing it.

H_ABSTAIN uses the parent HYBRID selector exactly, including `ABSTAIN_UNRESOLVED_COULD_CHANGE_WINNER`. H_SAFE makes one additional choice only when that selector abstains for an unresolved action: choose the highest-valued `GROUNDED` action with established consequence `>=0`, breaking equal grounded values by the frozen action order `ADVANCE,HOLD,RETREAT`. Label it `SAFE_GROUNDED_FALLBACK`, `action_justified=true`, and `optimality_established=false`. The unresolved assessment, both values, count, and receipt provenance remain intact; no model call breaks the tie. If all grounded alternatives are negative or absent, H_SAFE abstains just as H_ABSTAIN does. Normal grounded +1 ceiling selection and unseen-relation model generalization are unchanged. MODEL forecasts every action; FORCED_GROUNDED uses the latest receipt or neutral cold start point. Every action assessment is auditable and carries epistemic source.

Eight independent prospectively frozen scenarios in `protocol.py` receive matched authenticated controlled seed observations across four independent protected sessions. P1 has grounded +1 and an unresolved competitor; both hybrids use the old ceiling rule. P2 has unresolved HOLD and grounded neutral RETREAT; H_SAFE can execute the neutral fallback, then an observation-controlled HOLD receipt in B confirms the candidate. P3 has only a grounded −1 alternative and requires abstention. P4 has unresolved HOLD and ADVANCE plus grounded neutral RETREAT. P5 has unresolved ADVANCE that would yield +1 while the safe fallback is 0; a later controlled ADVANCE receipt confirms the candidate, and a second decision tests adaptation. P6 shares P2's four-receipt prefix but the next controlled HOLD receipt in A rejects the anomaly; its second decision tests recovery. P7 adds unseen ADVANCE to unresolved HOLD and grounded neutral RETREAT, preserving the frozen model role for the unseen exact relation. P8 restarts while HOLD is unresolved and RETREAT is established neutral, then tests the exact same fallback decision. P2 and P6's identical exact-value prefixes with opposite next receipts form the information-boundary pair. Only first decisions are matched across arms; after autonomous divergence, follow-up decisions are within-arm trajectories and reported descriptively.

H1/H2 stages for P8 must compare exact durable file hashes, grounded states, supporting receipt identities, and predecision H_ABSTAIN/H_SAFE decision status. After restart, a non-current Memory admission must fail without an authorized receipt, state change, or fallback-eligibility change. No model result may alter grounded state. Protected publication rejects unmatched or unauthorized actions.

Primary measures are realized consequence, incorrect confident selected points, abstentions, safe-fallback executions, harmful fallback executions (`realized consequence <0`), actions taken with `optimality_established=false`, missed positive opportunities, model calls, and epistemic integrity. Retrospective counterfactual world outcomes are analysis-only; they never enter the decision. A fallback yielding 0 while an unresolved action would have yielded +1 is `SAFE_BUT_SUBOPTIMAL_IN_HINDSIGHT`, not a false grounded claim. A future hidden-regime change can make historical grounded evidence stale; if a registered safe fallback itself yields −1, this is a harmful fallback and counts against support. `FALSE_CERTAINTY` counts any fabricated established status, any unresolved candidate flattened to a point, or any fallback labeled optimal. It must remain zero for support.

`SAFE_FALLBACK_SUPPORTED` requires complete receipt/replay/restart/perturbation integrity, `FALSE_CERTAINTY=0`, at least two more safe-fallback executions than H_ABSTAIN in matched first decisions, fewer abstentions, no harmful fallback, and no fallback chosen from an unestablished or negative relation. `ABSTENTION_PREFERRED` applies if H_SAFE executes any harmful fallback while H_ABSTAIN abstains at that matched decision. `MIXED` applies when integrity passes but neither support nor abstention preference applies. Any integrity failure is `INVALID`. Classification is architectural and descriptive in this small deterministic world.
