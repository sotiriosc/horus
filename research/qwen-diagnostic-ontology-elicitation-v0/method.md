## Questions and arms

Seven questions are prospective: minimal five-class discrimination; natural versus opaque labels; definition order; explanation burden; full structured burden; class-specific U/T/X/healthy-unusual/current weaknesses; primitive versus composite performance.

Natural definitions, unchanged from R2:

- SUPPORTED_CURRENT_DEFECT: Available current evidence supports a specific active structural or mechanical defect and distinguishes it from materially plausible benign alternatives.
- NO_SUPPORTED_DIAGNOSIS: The internally valid evidence is sufficient within the declared contract/input scope and supports no current defect. Unusual or undesirable behavior alone is insufficient.
- INSUFFICIENT_EVIDENCE: The evidence is internally valid but a current defect and a materially plausible benign explanation remain observationally indistinguishable.
- HISTORICAL_DEFECT_NOT_CURRENT: A defect is demonstrated for an older version, while supplied current mechanisms and observations show it is no longer active within the stated scope.
- INVALID_OR_CONTRADICTORY_EVIDENCE: The supplied evidence package contains incompatible immutable, version, capture or provenance facts and cannot support a valid operational diagnosis.

A: natural class only, JSON object with exactly classification. Definitions in the order above.
B: exact A request except definition lines in reverse order. JSON schema enum order remains unchanged, isolating definition order.
C: same class-only object as A, replacing each natural label with its assigned opaque label in definitions and schema. Only the opaque selected label is returned in classification. Retaining the object wrapper controls serialization burden. Two independent SHA-256-derived permutations of K7, M2, R9, T4, V6, using mapping-0 and mapping-1 namespaces with seed 731926581. Sort labels by SHA256(seed|mapping-N|label); zip against natural class order. Worlds ranked by SHA256(seed|map-assignment|world_id); alternate maps, ten worlds each. No semantic initials.
D: same natural definitions; exactly classification and rationale, rationale string length 1..500. No IDs, JSON pointers, interventions or solutions requested. Rationale receives no semantic credit.
E: the exact existing R2 diagnostic-schema.json (copied as schema-E.json), unchanged. Same observed/inferred/unknown separation, component and evidence citations, diagnostic statement, structured causal mechanism for D, strongest alternative, falsifier. Evidence grammar uses flat records with z+16hex IDs, so no schema adaptation is necessary. Field pointers address top-level fields of the decisive record. Generic instructions explain these conventions equally for all worlds. No gold witness scaffold enters a request.

All arms use a two-message fresh conversation, common system instruction and the same serialized raw evidence for a given world. No free prose in A-C. Native separated reasoning in every arm is private, not scored. The model receives no world/class/difficulty/family/mapping metadata except the single-prompt opaque definition mapping in C. The evidence compiler is unused, including in analysis.

## Generation specification (before materialization)

The 20 template slots in case-spec.json are fixed. D/H/U/T/X each have two primitive and two composite cases. New domains, arithmetic mechanisms and operating fields; no R2 world, record set, ID mapping, witness or prior response is used to construct cases. Reusing the ontology and generic flat record-ID grammar is deliberate. No version selection, authority precedence, entity binding, publication update, idempotence, or boundary-comparison mechanism is tested. T necessarily names old/current builds to test epistemic currentness; the violated operation itself is arithmetic, not version selection.

Choose each slot's integer q = 11 + int(SHA256(seed|quantity|slot)[:8],16) mod 19. Other constants and formulae are specified per slot. IDs derive independently as z + SHA256(seed|record|slot|role)[:16]. World IDs are w + SHA256(seed|world|slot)[:12]. IDs never encode class initials. Contract, input/mechanism and receipt are separate records. Each package declares a bounded one-operation scope, current build and component explicitly. D supplies the executed formula/parameter and immutable receipt, ruling out rounding, transport loss and unrecorded adjustments. H contract and receipt suffice within that same scope, sometimes unusual. U marks exactly one critical parameter UNKNOWN; executed formula and observation support two explicit offline completions, one compliant and one violating. T includes an old violating calculation and a current compliant calculation under an explicit current deployment. X includes two incompatible attestations of one immutable snapshot fact with no supplied basis for preferring one; thus an operational conclusion is unavailable.

Primitive worlds have four or fewer evidence records. Composite worlds add three relevantly distinguishable non-target records, including another component, an earlier non-target receipt and a later non-target relation. Distractors are clearly scoped and neither contradict nor change the target contract. Composite worlds contain multiple records/relations rather than obscure prose. Record order is SHA256(seed|record-order|world_id|id) sorted; identical across all arms. No adaptive generation or rejection sampling based on model behavior.

The generator writes evidence, offline gold with proofs/witnesses, five exact requests and a manifest. It must not read R2 cases or outputs. A separate static audit may read old evidence solely for non-reuse checks. Operational field names are new; generic ID/component/build/contract fields are structural grammar, not renamed R2 mechanisms. Gold/proofs are unavailable to the transport and model.

## Scoring and registered thresholds

Strict JSON: reject duplicate keys, NaN/Infinity, trailing prose, markdown wrappers, nonobjects and schema-invalid outputs. Python jsonschema Draft7 is authoritative, including uniqueItems and conditional constraints not fully enforced by llama grammar. For every arm, primary correct iff strict parse + frozen arm schema + recognized selected label + decoded class equals gold. No repair, reasoning/rationale rescue, retry, critic, or semantic interpretation. Finish length with a valid final is data; malformed/truncated finals are wrong. D's rationale semantics are not graded; prohibited ID/intervention requests are controlled in the prompt, not subjectively rescored. E classification correctness requires its full schema but not witness semantic correctness. Report parse/schema validity separately from class selection.

Recognized selected class: if a strict-JSON object has a valid classification label, record its decoded class even if another schema field is invalid; otherwise null. Class disagreement counts only pairs with two recognized semantic classes that differ. Report one/both missing separately, never manufacture semantic sensitivity from missing classes. Correctness transitions use primary correctness first: correct->wrong; wrong->correct; then both wrong with two distinct recognized classes = wrong->different wrong; all other pairs = unchanged. Report missing-label pairs and same-label/schema-validity flips separately to make the unchanged bucket transparent. No ambiguity about schema failures is repaired.

A minimal gate: >=17/20 AND >=3/4 in EACH class. Independently U+T+X gate >=10/12. A/B disagreements >=4/20 establishes ORDER_SENSITIVITY_PRESENT. A/C decoded disagreements >=4/20 establishes LABEL_SENSITIVITY_PRESENT. A minus D primary correct >=4 establishes RATIONALE_BURDEN_PRESENT; A minus E >=4 establishes STRUCTURED_CLASSIFICATION_BURDEN_PRESENT. Otherwise each effect is NOT_ESTABLISHED, never absent. Report accuracy delta (other minus A), exact discordant world IDs and four transition counts for every A-vs-other contrast. No inferential independence claim, p-value or attribution percentages.

For E's four gold D worlds, exact witness criteria are frozen: correct primary class; affected component exactly the gold singleton; contract/cause/effect/decisive IDs exactly the corresponding gold records; decisive_field exact top-level JSON pointer; observed_value and required_value exact type and value; evidence_ids includes the union of those required record IDs. Full witness requires all these. Description/diagnostic prose earns no subjective credit. Report each criterion, full witness /4, citation completeness /4, record and field localization /4, joint field+observed+required /4, required citation occurrences present/total and nonexistent evidence IDs. Across all E worlds report gold required-evidence coverage, complete citation sets /20 and nonexistent IDs. Gold citation sets: contract+input+receipt D/H/U, contract+both inputs+both receipts T (old input may be folded into old receipt to limit primitive facts), contract+both attestations X; witness IDs excluded from requests. These are operational scoring rules, not philosophical claims of unique natural-language explanation.

For every arm report per-class /4, primitive /10, composite /10, and per-class primitive/composite /2. Descriptive only. All-arms-strong means every arm meets the same 17/20, 3/4-each and 10/12 thresholds; E witness results remain separately reported.
