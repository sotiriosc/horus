## DSL, declared family, and independent identifiability

`dsl.py` specifies binary inputs, NOT/AND/OR/XOR/select, delays, reset-priority latches and thresholded modular counters. A toggle first changes one input; combinational observations use new inputs and old registers. Registers then update simultaneously. Inactive select branches still update. RESET observation does not advance the clock. All inputs/registers begin at zero. Register occurrences own separate storage; actuator leaves can be shared. The compiled VM and independent recursive interpreter are checked against each other across every catalog root and known manual traces.

Each machine has four actuators and four sensors, independently opaque-named. The declared hypothesis family is the full Cartesian product of the 4,632 sensor-root catalog entries, spanning BOTH cycles and BOTH complexity levels. It is a bounded finite grammar, not all possible programs in the DSL. The exhaustive checker filters every sensor root on every supplied observed bit and accepts a primary query only if all remaining consistent roots agree. Because the declared family is Cartesian, per-sensor exhaustive agreement proves complete observation identifiability without enumerating its full Cartesian product. Actual sampling family and complexity are never supplied to the checker to narrow hypotheses. Control cases additionally require agreement on every possible action path of up to four future steps.

Cycle-1 strata are delayed combination, input-gated delay, and conditional delay, using propagation/NOT/AND/OR/select and unit delays. Test expressions wrap training-family compositions in further gates and delays. Cycle-2 strata are parity interaction, persistent latch, and counter threshold. They introduce XOR, persistent reset/set state and modulo-3 threshold counters. Cycle-2 tests compose these with further two-step delays and latches. Exact templates and root restrictions are executable in `dsl.py`. Depth is operator-tree depth; delay length is the structural maximum accumulated delay along an expression path. These are separate from stateful-component counts.

## Frozen worlds and experimental unit

For EACH cycle: H=960, V=240, T=480, U(control)=40 distinct machines. Primary H/V/T contain one scheduled scored transition per machine. Thus primary paired inference has independent world endpoints, not correlated repeated endpoints treated as independent. Family counts are 320/80/160 for each H/V/T stratum; control strata are 14/13/13. Total prospective worlds: 3,440; primary endpoints: 3,360; control machines: 80. A cycle's control executes 1–4 actions per world per arm (at most 320 actual control transitions and 1,280 alternative prediction calls across two arms).

Every machine has 64 prospectively executed diagnostic transitions plus a RESET observation. These construction/diagnostic transitions are supplied context, not model-predicted harvest endpoints and NEVER supervision targets. This distinguishes initial observed experience from the NEW scheduled training-admissible action: every such action is predicted first, then executed, then authenticated. Per cycle diagnostics total 110,080 transitions across H/V/T/U; both cycles total 220,160. Replays for checking deterministic evidence are not newly acquired training examples.

There are 16 fixed correctness-independent diagnostic schedules. Schedule seeds are `20261001 + 10000 + index`; each contains 64 toggles. Its primary query input-state transition pair must not already appear in that schedule. This prevents direct lookup of an identical input transition in the diagnostic table; histories still provide repeated interventions for inference. Sampling seed bases are `20261001 + 10000000*(pool_index+1)` for H1,V1,T1,U1,H2,V2,T2,U2. A candidate seed is its pool base plus its one-based attempt. Acceptance rejects ambiguity, noninformative sensors, whole-machine equivalence, duplicate history and, for control, invalid target reachability; it never uses model outputs. Accepted seeds, counts, rejection counts and feature ranges are materialized in the freeze.

Across ALL pools, require distinct seed, exact program/world hash, normalized graph (all 24 global actuator permutations and sensor permutations), exact finite-state behavior under port renaming, normalized observed history and query endpoint. Exact behavioral equivalence is checked by reachable Mealy-machine minimization, stronger than graph deduplication. T/U use larger/deeper compositions than H/V. Primitive/template motifs intentionally recur; whole-machine novelty does not establish arbitrary-logic transfer or rule-template independence. Report this limitation explicitly.

Model messages contain ONLY opaque actuator/sensor lists, executed history, candidate action and a fixed task/schema instruction. Compact history rows are `[action, bits_in_sensor_order]`. The adapter never receives world ID/seed/family/program/hidden state/oracle explanations. Strict visible-input whitelists reject extra fields. Every exact semantic message, rendered prompt and token sequence is durably recorded before inference. No model Memory is used.

## Runtime and training recipe

Reuse the prior unchanged HF runtime: NF4 base with double quantization, BF16 compute, SDPA attention, all-linear LoRA r16/alpha32/dropout0/bias-none (280 projections; 64,225,280 trainable parameters), non-reentrant gradient checkpointing, all parameters CUDA-resident. Context 1,536; greedy nonthinking generation; max 96 new tokens; left-padded inference batches of four, EOS pad; TF32 disabled; runtime seed 20260930; CPU threads four; GPU allocation fraction .75. Structured output is instruction plus strict JSON parsing, without repair, retry or grammar forcing. Synthetic qualification tests all 16 four-sensor bit patterns and full-context training/inference.

D1: EVERY authenticated incorrect H1 transition plus equally many correct H1 replay exposures, stratified round-robin over nonempty `(family, actual four-bit observation)` strata with deterministic shuffling and replacement. Add 512 prospectively frozen prior temporal TRAINING replay exposures for the explicitly authorized retention exception. Those are selected only from already-admitted prior H1 error/correct-replay cases, excluding previous counterfactual and sealed cases. D2: EVERY incorrect H2 transition plus equally many correct H2 replay exposures, 256 fixed stratified Cycle-1 causal TRAINING receipt replays, and the same 512 prior temporal training exposures. Replay seeds and order are executable in `admission.py`. If no errors or no correct replay exists, record admission stop; do not redesign the sample. Wrong responses do not enter training inputs or targets.

V1/V2 are also predicted and actually executed by their respective incumbents during the harvest stage; their labels are raw-frozen executed observations used ONLY for diagnostic validation loss. They never enter optimizer updates. This avoids hidden-program validation labels. C1 continues C0; C2 continues C1. Base remains frozen. Two epochs; microbatch1/accumulation8; AdamW lr1e-4, betas(.9,.999), eps1e-8, weight decay .01, foreach=False; clip norm1; ceiling5% warmup then linear decay to0. Training-order seeds `20261001 + 1000*cycle + epoch_index`. Validation losses at epochs0/1/2 are diagnostic only. Final adapter only; no early stopping/checkpoint selection or scientific recipe adjustment. Freeze initial/final artifact hashes, tensor fingerprints, base fingerprints, losses, steps, gradients, memory, timing and save/reload fidelity before sealed inference.

## Prediction gates and retention

Strict output: exactly `next_observation` with exactly all four named sensors and integer0/1 values. Duplicate/extra keys and booleans are invalid. Invalid schema gives zero exact and bit accuracy. Report full-state exact accuracy, bit accuracy and family/depth/delay/hidden-component strata. Exact two-sided binomial McNemar on paired WORLD endpoints. Major stratum: prospectively defined category with n>=30.

Cycle1 supports `CAUSAL_WORLD_MODEL_LEARNING_SUPPORTED` iff ALL: exact gain>=10pp; paired p<.01; all three family strata improve (>0pp); no major stratum loss>3pp; candidate schema>=99%; adapter changed; base unchanged; leakage/oracle audit PASS; prior temporal exact>=530/540 (loss<=2pp) and schema540/540. ## Separate control claim

Same deterministic depth-ONE beam/greedy planner for all arms: width4 (all toggles), Hamming distance to target, supplied actuator-order tie break, budget4. It receives only actual observed history, target and model predictions. No hypothetical model trajectory is represented as executed history. Invalid predictions have infinite distance; if all invalid, select first actuator. The chosen real action is executed and appended; stop on observed target or budget. Targets are sampled independently of oracle solutions; offline oracle only rejects already-achieved/unreachable targets and checks identifiability. Oracle solution paths never enter the planner.

Report success/40, mean actions conditional on success for each arm, matched-success action means, cumulative selected-action prediction errors and failure modes. Separately support `CAUSAL_CONTROL_BENEFIT_SUPPORTED` iff >=6 additional successes, exact paired two-sided p<.05 and candidate mean actions on COMMON-success worlds <= incumbent+0.5 (at least one common success required). This matched estimand avoids treating harder newly solved worlds as a regression. Report both matched and unconditional conditional-on-success means for transparency. Same control rule on U2. This is bounded reactive control, not a long-horizon planning claim.
