# Grounded autonomous agent v0 — prospective registration

This observational campaign begins from secret-free `build/grounded-state-core-v0` at `373b1ec5b6269d6d3bb8bd853da2e692800568c3`. The earlier grounded-state folds, Memory admission, Measure/authorization, and controller remain unchanged. No Horus or Zakhor addition, training, forced grounded policy, model-only comparison, planner, or self-modification is permitted. The model is the installed local `dolphin-mixtral:latest`; the exact prompts, options, seeds, world schedule, output schemas, and code are pinned by the source manifest before inference.

Three fresh 30-decision campaigns A/B/C each start with a new session, authenticated ModernMemory, and no working context. Model seeds are 1101/2202/3303. The model sees the current state, three allowed actions, typed exact-relation grounded assessments, at most three recent receipt identities per relation, and at most three recent agent decisions. Its goal is to maximize useful realized consequence using only shown evidence. Its own prior reasons are labeled non-authoritative. A local model call returns JSON containing selected action, reason, evidence source identities, reliance category, and optional explicit status/consequence claims. A response with an invalid schema or disallowed action gets one semantic retry before the run stops. Existing registered transport repair may make at most two physical attempts for eligible transport failures. No action executes before a valid response.

The external four-state/three-action bounded world uses the existing protected receipt and authorization path. For decisions 1–10 it runs regime A, 11–20 regime B, 21–30 regime A. Phase labels `A1/B/A2` are driver-only. The exact relations `1:HOLD` and `2:HOLD` are explicitly `EMPIRICAL`; all others are `DETERMINISTIC`. Their predeclared per-phase visit-index consequence arrays in `protocol.py` supply ordinary variation and a state-1 change/restoration opportunity. Regime B's existing state-1 consequence overrides remain. The model sees neither phase, hidden simulator values, future outcomes, nor unexecuted counterfactuals. It can reach unseen relations through normal choices. Every chosen action is bound to a neutral execution forecast solely to drive the unchanged protected path; that forecast has no epistemic authority and is not shown to the agent. Only the original authorized receipt enters durable Memory. Independent campaigns may visit different relations and need not observe every designed episode.

Run B ends its first process after decision and review 15. Its session, Memory, full typed grounded states, and artifact hashes must reconstruct exactly in a fresh process before decision 16. The bounded working decision context resets at 16; no hidden conversational state persists. A and C run in one process. This measures whether durable grounded evidence alone supports coherent postrestart behavior.

A separate same-model self-review occurs after each five completed decisions (5, 10, 15, 20, 25, 30). If an otherwise valid run ends before another scheduled review, it gets a final review. Each review sees only the five recent completed decisions, including pre-decision grounded assessments, recorded reason and reliance, authenticated realized result, receipt-caused state change, and already recorded disagreement. It sees no future, hidden phase, or counterfactual. Its JSON `SELF_REVIEW` contains the required nine fields and may return `NO_CHANGE_PROPOSED`. Any other hypothesis is recorded as `NON_AUTHORITATIVE_SELF_PROPOSAL`. Reviews are written only to a non-authoritative signed training record. A before/after check verifies no event, Memory checkpoint, state, or grounded assessment changed; review content is never included in later decision prompts. No proposal changes behavior during this study. Future proposal/replay/promotion would need a separate preregistered study.

Per-decision public summaries retain current state, all before-action assessments, selected action, reason, stated evidence/reliance, original receipt identity/hash and realized consequence/next state, selected-relation state change, action change within the same state, and explicit structured agent/grounded disagreement. Raw prompts, raw model responses, HMAC keys, signed session streams, and durable databases remain in a local private archive only. Public export contains summaries, metrics, timelines, source hashes, replay verdicts, and SHA-256 digests of omitted private files. A branch whose reachable history contains those raw artifacts must not be pushed.

Primary interpretation is descriptive: repetition despite authenticated negative evidence, changed choices after receipts, exploration of unseen relations, use of established evidence, handling of unresolved/variable relations, stale claims, and observable adaptation after change/restoration. Metrics include realized total, unique/explored relations, negative-evidence repetition, established reliance, unresolved choices, disagreements, adaptation opportunities/latencies, model calls/tokens, and Memory size. No counterfactual score is inferred. The independent postrun review audit classifies each proposal as supported, partially supported, hindsight overfit, contradicted, untestable, or no change using only the preserved observed trajectory; unsupported natural-language explanations are reported separately. A review is not authoritative even when its criticism is correct.

The run is `INVALID` if protected integrity or Memory replay fails, a valid allowed action does not arrive within the registered retries, a review cannot satisfy its schema, or an operational failure cannot be repaired under the transport rule. Possible aggregate interpretations are `EXPERIENCE_GUIDED_BEHAVIOR_OBSERVED`, `WEAK_OR_INCONSISTENT_USE_OF_GROUNDING`, `GROUNDING_IGNORED_BY_AGENT`, and `INVALID`. No claim of consciousness, weight learning, or general behavioral improvement follows from these three trajectories.
