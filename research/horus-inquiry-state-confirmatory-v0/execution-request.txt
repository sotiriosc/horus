# Crucial open-world rule

Never let the model conclude:

“I tested every known option, therefore I know the truth.”

Allow the explicit state:

UNRESOLVED_BEYOND_CURRENT_DISCRIMINATION

This means:

the current evidence, hypotheses, measurements, or available interventions are insufficient to distinguish what remains.

It is a legitimate output.

It is not failure.

# What carries forward

Carry forward:

AUTHENTICATED REALITY

- executed experiments;
- observations;
- deterministic bookkeeping.

Do NOT automatically carry forward:

- previous causal explanations;
- previous unresolved-question prose;
- model confidence;
- preferred hypothesis.

At each step the model reconstructs its present understanding from the evidence again.

This tests whether an inquiry frontier can emerge from reality rather than becoming a self-reinforcing narrative.

# Important failure interpretations

If B confirms but O does not:

Grounded bookkeeping is useful, but explicit self-generated inquiry-frontier reasoning adds no established benefit yet.

If O improves:

There is evidence that the model can reconstruct useful open questions from authenticated observations rather than relying only on a predefined remaining-action map.

If neither B nor O improves:

The pilot did not replicate. Stop.
