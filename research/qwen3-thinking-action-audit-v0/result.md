# Qwen3 native-thinking action audit v0 — result

**Classification: `INTERFACE_INCOMPATIBLE` under the frozen request and 512-token output cap.** The first of three preregistered preflight probes exhausted its entire 512-token completion budget in the separately returned reasoning channel. The runtime returned `finish_reason=length`, zero final-content characters, and no `selected_action`. The strict parser correctly rejected it. No world action was executed.

The preregistration required all three probes to return a separate nonempty reasoning channel **and** one complete, unambiguous final action. It also required stopping at the first failure, without retrying, raising the budget, weakening parsing, or proceeding to Stage A/B. Accordingly, there was exactly **one** new Qwen model call in this study, no Stage A sensitivity calls, no Stage B autonomous decisions, and no new Dolphin inference.

The physical attempt used the pinned Qwen3-14B Q4_K_M artifact (`500a8806e85ee9c83f3ae08420295592451379b4f8cf2d0f41c15dffeb6b81f0`) and llama.cpp build `526c43b8f7dfea9032e9f35e7a1be9183ca7cc20`, with native thinking enabled and separated by the registered server flags. The frozen all-unseen D projection and seed `88101` yielded an HTTP response after **14.645 seconds**. It contained 334 prompt tokens and 512 completion tokens; the separate reasoning field had 2,394 characters, while final content was empty. The pinned local tokenizer counted **510 reasoning-token proxies and 0 final-output tokens**; the original response reported **0.156 seconds prompt processing** and **14.482 seconds reasoning/generation**. The proxy does not claim exact runtime-internal phase accounting. This is an interface/length failure in the **preregistered configuration**, not evidence that Qwen3 can never produce a valid thinking-mode action under another prospectively specified budget or interface.

The prior non-thinking substitution study remains unchanged: `QWEN_FAST_BUT_BEHAVIORALLY_UNSUITABLE`, with `HOLD` on 90/90 model-mediated autonomous choices and recommendation `RETAIN_DOLPHIN`. This audit cannot determine whether that fixation reflects a model limitation or the fast non-thinking interface: the thinking-mode action interface failed before the semantic sensitivity gate. No active-model switch, policy change, training, or prompt redesign follows from this result.
