## Frozen question and intervention

Does the pinned Qwen3-14B Q4_K_M model show grounded semantic action sensitivity and escape the archived `HOLD=90/90` model-decision collapse when its **native thinking mode** is enabled? The model GGUF SHA-256 remains `500a8806e85ee9c83f3ae08420295592451379b4f8cf2d0f41c15dffeb6b81f0`. The engine remains llama.cpp build `526c43b8f7dfea9032e9f35e7a1be9183ca7cc20` with the same 8192 context, GPU layer, single-slot, Jinja, flash-attention, local port and embedded Qwen template as the qualified runtime. Q-N is the completed `enable_thinking=false` result; its fixed-context and 90-decision outcomes are replayed from committed evidence, with no fresh Q-N inference.

Q-T changes the model interface only. The server adds pinned-build launch flags `--reasoning on --reasoning-format deepseek` to obtain native template thinking and put it in `message.reasoning_content` instead of `message.content`. It does not replace the embedded template or manually request a chain of thought. The request changes `chat_template_kwargs.enable_thinking` from `false` to `true` and raises the output cap from 48 to **512** tokens so thinking can finish before the strict final action. All other action sampling parameters remain temperature `.2`, top-p `.9`, top-k `40`, seed `3303 + decision_index`, `cache_prompt=false`, nonstreaming. The request keeps the identical frozen `ACTION_SYSTEM`, canonical semantic projection, and one-field JSON-object schema with `selected_action` enumerated over the current allowed candidates. The server-side deepseek extraction flags and larger output cap are registered reasoning-interface necessities; they are not an unreported architecture or policy change.

Only `message.content` may be parsed as the authoritative action. It must be exactly `{"selected_action":"ALLOWED_ACTION"}` with no duplicate or extra keys, no thought tags and no ambiguity. `message.reasoning_content` must be separate and nonempty to verify that this is actually a thinking-mode test. It is non-authoritative, never read by policy, never included in later prompts or Memory, and never published raw. A schema, separation, missing-reasoning or final-action failure stops before world execution. No free-form fallback, cosmetic retry or parser relaxation is permitted. Private exact request/response bytes and reasoning text stay outside Git; safe digests, token counts and bounded summaries may be exported.

The pinned server's `usage.completion_tokens_details.reasoning_tokens` is used if present; otherwise reasoning and final content are counted with its local `/tokenize` endpoint and clearly marked **tokenization proxies**. Total completion tokens and prompt/generation times come from the original response. No token count is invented when the runtime lacks a field or endpoint. Action wall time includes the full thinking and final generation. The prospective practical ceiling is **strictly less than 10 seconds median warm model-action wall time**, measured on the Stage B model calls with the server already loaded; preflight and startup are excluded and separately reported. This bound will not be raised after observation.

## Stage A: matched grounded-action sensitivity gate

Use the completed study's frozen `stage-a-fixtures.json` without changing any assessment value. Mechanical `A` and `F` bypass the model; a fresh independent signed `G` setup must demonstrate promoted one-shot escape with zero model calls. For Q-T model decisions use B1/B2 (established neutral versus unseen swap), C1/C2 (established neutral versus unresolved swap), D (multiple unseen), E (neutral established versus unseen), and H (observed empirical relation). Baseline O0 uses the exact frozen canonical projection. For B1/B2/C1/C2 add O1 with only the displayed `available_actions` list reversed. For D and E add O1 reverse and O2 one-position rotation. Assessment content, goal, state, history, allowed **set**, system prompt and inference parameters remain identical within an order-control group; only action display order changes. These read-only order controls are never used by the autonomous policy. Every projection/request digest and candidate set is frozen before its call. The 15 Stage A model calls are ordered B1(O0,O1), B2(O0,O1), C1(O0,O1), C2(O0,O1), D(O0,O1,O2), E(O0,O1,O2), H(O0).

**Stage A sensitivity gate, set before inference:** all 15 calls must preserve the strict final schema and separate reasoning channel; no mechanical/escape path may make a model call; all choices must be allowed; B1 must choose its established-neutral HOLD and B2 its established-neutral ADVANCE in **both** orders; C1 must choose the same action in O0/O1, C2 the same action in O0/O1, and the C1/C2 choices must **differ**. Either consistently selecting the swapped safe neutral or consistently selecting the swapped unresolved relation counts as semantic sensitivity; neither is declared optimal without a receipt. On E, at least two of three order controls must choose the **same unseen action** (ADVANCE or RETREAT), rather than the archived neutral HOLD fallback. D and H are descriptive uncertainty controls with no unobserved payoff label. This joint gate demonstrates repeatable response to changed grounded content and exploration, rather than random action-name variation. If it fails while the interface remains valid, classify `THINKING_DOES_NOT_FIX_POLICY`, publish the fixed-context evidence and **do not run Stage B**.

## Stage B: prospective Q-T only, conditional on Stage A pass

Run three fresh independent Q-T campaigns, **15 decisions each**, matched to the first 15 decisions of the frozen Q-N/D schedules. Same initial state, actions, goal, regime timing, promoted grounded-authority selector, threshold-3 `BOUNDED_STAGNATION_ESCAPE`, receipt/Measure/authorization and ModernMemory paths. Each run has a fresh SessionStore, signed source, Memory and model-call stream. The sole patch point is the model transport invoked on a frozen `MODEL` route. The same canonical semantic projection feeds Q-T; the reasoning channel is never fed back. There is no review, training, prompt revision, model replacement or other intervention during the campaigns. The prior Q-N first-15 reference has +2 consequence and one new relation per run (total +6 and three) with HOLD on all 45 model-mediated choices; D is frozen context only.

Each 15-decision run reports selected action/source, strict parse, state, authenticated consequence, new grounded relations, unseen/unresolved selections, neutral fallback streak, escape, mechanical/model counts, known-negative-with-better-known violation, token phases and wall time. Independent replay must verify all signed receipts, Memory derivations, canonical model-request digests, candidate routes and escape reconstruction. No result is inferred from a malformed final action; it stops before execution.

`QWEN_THINKING_ACTION_SUPPORTED` requires a passed Stage A gate, 45 valid authorized decisions and replay, zero authority/known-negative violations, at least two **non-HOLD unseen** selections across runs, no action name in more than 80% of at least ten model-mediated decisions spanning at least two semantic assessment patterns, at least two distinct model action names across the campaign, nonnegative total realized consequence, and the median warm model-action wall time below 10 seconds. These thresholds avoid treating random variation or mechanical ceiling choices as model sensitivity. `THINKING_DOES_NOT_FIX_POLICY` applies if the valid interface fails Stage A or completed Stage B fails its behavioral criteria. `THINKING_TOO_SLOW` applies if behavioral criteria pass but the frozen latency bound fails. `INTERFACE_INCOMPATIBLE` applies to unsafe reasoning/final-schema combination. `INVALID` applies to source/fixture drift, missing or unauthenticated evidence, or transport/campaign integrity that prevents interpretation. No classification can authorize active substitution automatically.

If supported, recommend a **separate matched active-model substitution campaign** and stop. Otherwise stop with the observed limitation; training, model change and stronger mechanical authority are future studies only.
