# Horus question network

This document records open questions. It is not experimental evidence and does
not add runtime claims.

## Engineering questions

- How broadly does grounded experience → Memory → changed behavior transfer?
- What should Map's final role be?
- What should Explorer's final role be?
- Which decisions should remain mechanical?
- How should the system distinguish pattern, noise and regime change?
- How should Zakhor and Horus interact?
- When and how should authenticated experience affect model weights?
- What long-run endurance and drift behavior is acceptable?

## Foundational questions

- Is relation a useful primitive?
- What constraints connect a whole and its parts?
- Can emergence operate in both directions?
- How does experience differ from stored data?
- How should contradiction persist without erasing history?
- In what sense must a destination answer to consequences?
- What can the sentence, loop, funnel and Hamakom ideas clarify?

## Analogy and question space

These are analogies and questions, not established physics and not Horus claims:

- phase as relational
- measurement as interaction
- localization changing relations
- interaction history as potentially memory-like
- quantum structure as an analogy for relation/context

## Future Zakhor endurance requirement

Eventual Zakhor testing should include:

- early, middle and late windows
- cumulative drift
- worst-window degradation
- perturbation recovery
- restart recovery

These questions are intentionally outside the Horus v0 runtime.
